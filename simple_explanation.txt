Simple Explanation of the Plant Disease Classification System

1. Project Overview

The AI-Assisted Plant Disease Classification System is a web-based application designed to help users identify possible plant diseases from images of plant leaves. The system uses artificial intelligence and image classification to analyze an uploaded image and provide the most likely plant and disease category from the supported classes.

The project is intended to support farmers, gardeners, students, and other users by providing quick preliminary information about plant health. The result is an AI-assisted estimate and should not be considered a guaranteed agricultural diagnosis. Important treatment and farming decisions should be confirmed by a qualified agricultural expert, plant pathologist, or agronomist.

2. Problem Statement

Plant diseases can damage crops, reduce agricultural productivity, affect farmer income, and lower food quality. Identifying a disease through visual inspection can be difficult, especially for people without specialist knowledge. Agricultural experts may also be unavailable, expensive, or difficult to reach.

As a result, users may identify diseases incorrectly or apply unsuitable treatments. This project aims to provide an accessible image-based tool that can assist users in recognizing possible plant diseases at an early stage.

3. Main Objective

The main objective of this project is to develop a web application that analyzes plant leaf images and provides an AI-assisted classification of the most likely plant disease or healthy plant condition.

The planned system will support 38 plant and disease classes, including healthy plant classes. The final model performance and class mapping will be verified during the model research and training stage.

4. How the System Works

1. Image Upload
   The user captures or selects an image of a plant leaf and uploads it through the web application.

2. Image Validation and Preparation
   The application checks whether the uploaded image is suitable for analysis. The image is then prepared according to the preprocessing requirements established during model research and training.

3. AI-Based Image Analysis
   The image is analyzed by the plant disease classification model. The selected model architecture for the project is EfficientNetB3 using TensorFlow and Keras.

4. Classification Result
   The system returns the most likely plant and disease category from the supported classes. Where applicable, the application may also present confidence information and other possible classifications.

5. User Interpretation
   The result is presented as an AI-assisted estimate. Users are informed that image quality, training data, and real-world conditions can affect the result.

5. Expected Benefits

- Provides quick preliminary information about possible plant diseases.
- Helps users become more aware of plant health problems.
- Supports early investigation before consulting an agricultural expert.
- Provides an accessible web-based interface for image classification.
- Creates an educational project demonstrating the use of artificial intelligence in agriculture.

6. Confirmed Technology Stack

Frontend
- Next.js — web application framework.
- TypeScript — frontend programming language.
- Tailwind CSS — interface styling.

Backend
- Python — backend and machine-learning programming language.
- FastAPI — backend API framework.
- Pydantic — data validation for API requests and responses.

Machine Learning
- TensorFlow and Keras — machine-learning framework.
- EfficientNetB3 — selected image-classification model architecture.
- NumPy — numerical and image-array operations.
- Pillow — image decoding and image handling.

Database, Authentication, and Storage
- Supabase PostgreSQL — database for application data.
- Supabase Auth — user authentication and session management.
- Supabase Storage — storage for uploaded plant images.

Development Tools
- Docker and Docker Compose — local development and application setup.
- pytest — backend and machine-learning testing.
- Git and GitHub — version control and project collaboration.

7. Limitations and Responsible Use

The system is designed to provide AI-assisted classification, not professional agricultural diagnosis. Its performance may be affected by unclear images, poor lighting, background objects, unfamiliar plant conditions, or images outside the supported classes. The system should not automatically prescribe pesticides or replace professional agricultural advice.

8. Possible Future Enhancements

The following features are possible future enhancements and are not considered part of the current basic system. They may be added if sufficient time and resources are available.

- User accounts and prediction history so users can review previous analyses.
- Detailed disease information, including symptoms, prevention, and educational references.
- Top alternative predictions to show other possible classifications.
- Image-quality guidance to help users upload clearer and more suitable photographs.
- User feedback so predictions can be reviewed and used to improve future model development.
- Support for additional plant species and disease classes after suitable data is collected and evaluated.
- Multilingual support for users from different regions.
- A mobile application or camera-based live scanning feature.
- An expert review feature that allows users to request confirmation from an agricultural professional.
- Improved testing with real-world field images and continuously updated training data.
- Administrative tools for managing supported classes and educational disease information.

This project demonstrates how artificial intelligence, web technologies, and agricultural information can be combined to support plant disease awareness and informed decision-making.
